# Lan7 Creative UX & Next-Gen Interface Patterns

Специализированный каталог креативных решений и дизайн-паттернов для сетевого движка Lan7. Предназначен для создания премиального пользовательского опыта при работе с L2/L3 топологиями, оборудованием и телеметрией без использования тяжелых сторонних библиотек (Zero-NPM, Vanilla JS, нативный CSS).

---

## 1. Пространственный UX холста (Spatial Topology & Canvas)

### 1.1. Radial Halo Menu (Кольцевой контрол быстрого действия)
* **Поведение**: При одиночном клике на коммутатор/маршрутизатор на холсте Cytoscape вокруг узла раскрывается кольцевое меню с радиусом `48–64px`.
* **Сектора управления**:
  * `12:00` (Top) — **Быстрая диагностика / Ping HUD** (зеленый пульсирующий бейдж).
  * `03:00` (Right) — **Матрица портов & VLAN Faceplate** (открытие мини-панели).
  * `06:00` (Bottom) — **Таблица FDB / ARP & Дельта хостов**.
  * `09:00` (Left) — **Конфигурация & NCM бэкап** (SSH статус, diff).
* **Кинетика появления**: Масштабирование из центра (`transform: scale(0.6) -> scale(1.0)`, `opacity: 0 -> 1`) за `140ms` с таймингом `cubic-bezier(0.16, 1, 0.3, 1)`.
* **Автозакрытие**: Клик в пустую область холста или нажатие `Escape` плавно сворачивает меню.

### 1.2. Ghost Connections & Snap Target (Магнитная привязка связей)
* **Поведение**: При ручном создании линка между устройствами (`manual link drag`):
  * Все валидные целевые порты и коммутаторы подсвечиваются мягким неоновым ореолом (`box-shadow: 0 0 12px var(--color-primary-glow)`).
  * При приближении курсора на расстояние `12px` срабатывает кинетическое притяжение (snap target), предотвращая случайные промахи.
  * Если тип соединения недопустим (петля без STP, несовместимость интерфейсов), ореол меняется на предупреждающий янтарный цвет.

### 1.3. Contextual HUD Overlays (Парящие панели)
* **Поведение**: Плавающие оверлеи (мини-карта, легенда типов линков, тулбар слоев) фиксируются в углах экрана либо якорятся относительно координат узла.
* **Стилизация**: `background: rgba(18, 24, 38, 0.75)`, `backdrop-filter: blur(12px)`, тончайшая рамка `border: 1px solid rgba(255, 255, 255, 0.08)`.
* **Изоляция событий**: Обязательный вызов `isolateOverlayEvents(element)` и `e.stopPropagation()` на события мыши/колеса, исключающий нежелательный зум и сдвиг канваса.

## 2. Аппаратный скевоморфизм и плотность данных (Hardware Metaphor & Data Density)

### 2.1. Switch Port Faceplate (Интерактивная панель коммутатора)
* **Форм-фактор**: Сетка портов 2×12 (24 порта) или 2×24 (48 портов) с шагом `2–4px`, имитирующая реальную лицевую панель стоечного свитча.
* **Визуализация портов**:
  * **Up / Active**: Изумрудный индикатор (`#10b981`) со сглаженным светодиодным свечением.
  * **Down / Idle**: Приглушенный графитовый (`#475569`).
  * **Blocked / STP Loop**: Предупреждающий янтарный/красный (`#ef4444`).
  * **Trunk / Uplink**: Тонкая контрастная рамка вокруг порта (двойной контур).
  * **SFP / Оптика**: Квадратный порт с золотисто-синей маркировкой; **RJ-45 Медь**: традиционный трапециевидный контур.
* **Micro-Tooltip (Ховер задержка 100мс)**:
  * Номер порта (`gi1/0/1`), статус Duplex/Speed (`1G Full`), текущий Access VLAN или Trunk Tagged list, текущий битрейт TX/RX.

### 2.2. Компактная телеметрия без джиттера (Tabular Metrics)
* Все цифровые счетчики пакетов, скорости (Kbps/Mbps/Gbps), IP и MAC-адреса выводятся моноширинным шрифтом:
  ```css
  font-family: var(--font-mono, 'JetBrains Mono', monospace);
  font-variant-numeric: tabular-nums;
  ```
* **Прогрессивное раскрытие (Progressive Disclosure)**:
  * По умолчанию отображается агрегированная строка статуса (например, `24 Up / 2 Down • 1.4 Gbps`).
  * Клик или раскрытие аккордеона разворачивает детальную разбивку по портам без перезагрузки контекста.

## 3. Физика микроинтеракций и анимация (Micro-Interactions Physics)

### 3.1. Кривые ускорения и тайминги
* **Snappy Spring (Появление панелей, открытие дропдаунов, радиальных меню)**:
  ```css
  transition: transform 200ms cubic-bezier(0.16, 1, 0.3, 1), opacity 150ms ease-out;
  ```
* **Gentle Ease-Out (Угасание подсветки, скрытие оверлеев)**:
  ```css
  transition: transform 140ms cubic-bezier(0.25, 0.8, 0.25, 1), opacity 120ms ease-in;
  ```

### 3.2. Живой кабель (Live Cable Pulse)
* Отображение активного трафика через нативный SVG `stroke-dashoffset` без внешних библиотек:
  ```css
  @keyframes lanCablePulse {
    0% { stroke-dashoffset: 24; }
    100% { stroke-dashoffset: 0; }
  }
  .link-active {
    stroke-dasharray: 4 6;
    animation: lanCablePulse 0.8s linear infinite;
  }
  .link-high-load {
    animation-duration: 0.35s;
    stroke: var(--color-warning, #f59e0b);
  }
  ```

### 3.3. Zero-Slop Empty States
* Вместо статичной серой надписи «Данные отсутствуют»:
  * Контекстная иллюстрация (тонкие чистые SVG-линии сетевого узла).
  * Четкое объяснение причины на языке сетевика («Коммутатор доступен по ICMP, но SNMP Community не подошел»).
  * Прямая кнопка решения («[Запустить проверку Community]» или «[Открыть параметры авторизации]»).

# DuckDock / TouchWM

Легковесный кастомный оконный менеджер (Tiling Window Manager + Dashboard) для вспомогательного 7-дюймового сенсорного IPS-дисплея (800×600) в Windows 10/11.

---

## 🎯 Назначение

Обеспечивает роль сенсорной оболочки для второго монитора:
* **Stealth Touch**: Предотвращает потерю фокуса в полноэкранных играх и средах разработки на основном 27" мониторе (`WS_EX_NOACTIVATE` + возврат фокуса через WinEvent хуки).
* **Anti-Cursor Warp**: Автоматически возвращает системный курсор мыши на основной монитор после касания сенсорного экрана.
* **Borderless Tiling (720x600)**: Встраивает сторонние нативные окна (например, `happ.exe`) с удалением рамок и заголовков.
* **Аппаратная телеметрия**: Считывание датчиков процессора, видеокарты и памяти из Shared Memory AIDA64 (`mmap`).
* **Медиаплеер / YouTube**: Сенсорные элементы управления мультимедиа с изоляцией декодирования на iGPU (AMD Radeon Graphics Ryzen 7 7700).
* **Software Dimmer**: Сквозной слой регулировки яркости (0.0 .. 0.95) без поддержки DDC/CI.

# Дизайн-документ (Tech Spec): Проект «duckdock / TouchWM»

* **Версия:** 0.1.0-draft
* **Целевая платформа:** Windows 10/11 (x64), Python 3.11+, PySide6, pywin32 (`ctypes`).
* **Целевое устройство:** Вспомогательный 7" IPS сенсорный дисплей (800×600, подключен по HDMI к материнской плате — iGPU AMD Radeon Graphics на Ryzen 7 7700 + USB для тач-сенсора).
* **Основной монитор:** 27" (подключен к дискретной видеокарте dGPU).

---

## 1. Концепция и назначение
Создание легковесного кастомного менеджера окон и дашборда (Tiling Window Manager + Dock) для вспомогательного сенсорного экрана 800×600. Приложение берет на себя роль «оболочки» второго монитора: управляет расположением сторонних окон, рендерит собственные виджеты (телеметрия, медиа) и предотвращает потерю фокуса на основном 27" мониторе (например, во время полноэкранной игры или работы в IDE) при касании тачскрина.

---

## 2. Аппаратный уровень и рендеринг (iGPU vs dGPU)

Поскольку 7" экран физически подключен к HDMI на материнской плате (iGPU Ryzen 7 7700), а 27" монитор — к дискретной видеокарте (dGPU), в Windows 10/11 работает механизм **Cross-Adapter Scan-Out (CASO)**. По умолчанию Windows может рендерить тяжелые приложения (включая браузер и Qt WebEngine) на основной мощной видеокарте, а затем копировать кадры по шине PCIe в память iGPU для вывода на маленький экран.

### 2.1. Жесткое разделение нагрузки
1. **Привязка в настройках графики Windows:**
   * В `Параметры -> Система -> Дисплей -> Графика` добавить исполняемый файл Python-интерпретатора (или собранный `.exe`), а также `happ.exe` и `aida64.exe`.
   * Выбрать для них режим **«Энергосбережение» (Power Saving)** — *AMD Radeon(TM) Graphics* (встройка Ryzen 7 7700). Это полностью снимет нагрузку с основной видеокарты и исключит микрофризы в играх при обновлении графиков или видео на втором экране.
2. **Настройка рендеринга PySide6 / Chromium:**
   * При использовании `QWebEngineView` (для YouTube) передать флаги командной строки до инициализации `QApplication`:
     ```python
     import os
     # Оптимизация под легковесный рендеринг на iGPU
     os.environ["QTWEBENGINE_CHROMIUM_FLAGS"] = "--enable-gpu-rasterization --enable-zero-copy --disable-gpu-compositing"
     ```
3. **Изоляция DPI (Критично для мультимониторных систем):**
   * Вызов `ctypes.windll.shcore.SetProcessDpiAwareness(2)` (`PROCESS_PER_MONITOR_DPI_AWARE`) в самом начале `main.py` обязателен, чтобы координаты `800x600` не искажались масштабированием основного 27" экрана (например, 125% или 150%).

## 3. Механика «Stealth Touch»: Фокус и Курсор

При нажатии пальцем на сенсорный экран в Windows возникают две стандартные проблемы:
1. **Потеря фокуса (Focus Stealing):** Активное окно на основном мониторе теряет фокус (игра может свернуться или отключить звук).
2. **Прыжок мыши (Cursor Warp):** Системный курсор телепортируется на второй экран в точку касания.

### 3.1. Запрет перехвата фокуса для самой панели (PySide6 + WinAPI)
Использование расширенного стиля окна Windows `WS_EX_NOACTIVATE` (`0x08000000L`). Окно с этим флагом принимает клики и нажатия, но **ОС не делает его активным** и не забирает фокус у текущего окна на основном мониторе.

* **Реализация:**
  После инициализации `QMainWindow` модифицируем стиль через `win32gui`:
  ```python
  import win32gui, win32con

  hwnd = int(self.winId())
  ex_style = win32gui.GetWindowLong(hwnd, win32con.GWL_EXSTYLE)
  win32gui.SetWindowLong(
      hwnd, 
      win32con.GWL_EXSTYLE, 
      ex_style | win32con.WS_EX_NOACTIVATE | win32con.WS_EX_APPWINDOW
  )
  ```
* В Qt дополнительно выставляется атрибут `self.setAttribute(Qt.WA_ShowWithoutActivating)` и на все кнопки сайдбара — `button.setFocusPolicy(Qt.NoFocus)`.

### 3.2. Возврат фокуса при клике по сторонним окнам («Focus Guardian»)
Сторонним окнам (`happ`, `AIDA64`) нельзя безусловно выставить `WS_EX_NOACTIVATE`, так как они могут перестать обрабатывать клики по внутренним контролам.
* **Алгоритм работы:**
  1. Фоновый поток хранит `last_primary_hwnd` — дескриптор последнего активного окна, расположенного в координатах основного 27" монитора.
  2. При фиксации переключения фокуса (`EVENT_SYSTEM_FOREGROUND` через `SetWinEventHook`) на окно в координатах 7" монитора запускается таймер на 50–100 мс (для завершения обработки клика целевым приложением).
  3. Через 100 мс скрипт принудительно возвращает фокус на `last_primary_hwnd` через `SetForegroundWindow` (в связке с `AttachThreadInput` для обхода блокировки Windows).
  4. **Исключение:** Режим ввода текста (переключатель `lock_toolB` на сайдбаре), который временно отключает возврат фокуса, чтобы можно было набрать запрос в поиске YouTube с физической или экранной клавиатуры.

### 3.3. Возврат курсора на основной экран (Anti-Cursor Warp)
1. Скрипт отслеживает и сохраняет последнюю позицию курсора на основном экране `last_primary_cursor_pos` (обновляется только тогда, когда координаты `(x, y)` находятся в пределах первого монитора).
2. При детекте тач-события на втором экране (`QEvent.TouchBegin` или через низкоуровневый хук `WH_MOUSE_LL` с флагом тач-инъекции `LLMHF_INJECTED`) через 20–30 мс после клика вызывается `win32api.SetCursorPos(last_primary_cursor_pos)`.

## 4. Архитектура интерфейса и Layout (800×600)

Разрешение 800×600 (соотношение 4:3) требует отказа от стандартных заголовков и рамок окон Windows (экономия ~32px по высоте).

### 4.1. Сетка экрана (Grid Specification)
* **Общий размер окна:** `800x600`, флаг `Qt.FramelessWindowHint`, жесткая привязка к `QScreen.geometry()` второго дисплея.
* **Левый док (`sidebar_frame`):** `80x600 px` (10% ширины).
  * Размер кнопок: `64x64 px`, отступы `8 px`, скругление `12 px` (стиль Dark UI / Glassmorphism).
  * Состав элементов сверху вниз:
    1. `yt_toolB` — YouTube / Медиаплеер.
    2. `sensors_toolB` — Телеметрия (AIDA64 / Системные датчики).
    3. `happ_toolB` — Управление прокси/туннелями (`happ`).
    4. `audio_toolB` — Быстрый микшер громкости приложений.
    5. *Spacer (вертикальная распорка)*
    6. `lock_toolB` — Тоггл режима «Stealth Focus / Ввод с клавиатуры».
    7. `sleep_toolB` — Программное отключение/затемнение экрана (Dimmer).
* **Рабочая область (`workspace_stackedW`):** `720x600 px`.

### 4.2. Механика работы со сторонними окнами (Borderless Tiling)
Вписывание сторонних нативных окон (`happ`, внешние утилиты) в контейнер `720x600`:
1. Поиск `hwnd` окна по имени процесса (`psutil` + `win32process.GetWindowThreadProcessId`).
2. Удаление системной рамки и заголовка через WinAPI:
   ```python
   style = win32gui.GetWindowLong(hwnd, win32con.GWL_STYLE)
   style &= ~win32con.WS_CAPTION
   style &= ~win32con.WS_THICKFRAME
   win32gui.SetWindowLong(hwnd, win32con.GWL_STYLE, style)
   ```
3. Позиционирование окна ровно в рабочую зону (`X = monitor2.x + 80`, `Y = monitor2.y`, `W = 720`, `H = 600`) через `SetWindowPos` с флагом `SWP_FRAMECHANGED | SWP_NOACTIVATE`.
4. При переключении вкладки в сайдбаре неактивное стороннее окно скрывается (`SW_HIDE`), а активное отображается (`SW_SHOWNOACTIVATE`).

## 5. Спецификация функциональных модулей

| Модуль | Способ реализации | Плюсы и особенности |
| :--- | :--- | :--- |
| **1. YouTube / Media** | Встроенный `QWebEngineView` с инжектом пользовательского CSS/JS | Полный контроль над тач-событиями, отсутствие рамок браузера, блокировка рекламы через `QWebEngineUrlRequestInterceptor`, крупный интерфейс. |
| **2. Датчики (AIDA64)** | Чтение Shared Memory (`AIDA64_SensorValues`) через `mmap` в Python + карточки в PySide6 | Отказ от захвата окна AIDA64. Собственная верстка датчиков в едином стиле, вывод температур Ryzen 7700, загрузки GPU, сети и пинга. |
| **3. happ (Proxy UI)** | Внешний процесс (`hwnd`), захват в зону `720x600` без рамки (`Borderless`) | Нативное окно вписывается в правую часть экрана. Автоматическое разворачивание из трея при выборе вкладки. |
| **4. Media Overlay** | Системный `winsdk` (Windows Media Control) | Плавающий мини-бар поверх любого окна: название трека/видео, кнопки Play/Next/Volume без перехода во вкладку YouTube. |

## 6. Дополнительные сервисные функции (QoL)

1. **Программный Dimmer (Ночной режим / Автозатемнение):**
   Поскольку 7" экраны часто не поддерживают управление подсветкой через DDC/CI из Windows, поверх окна `800x600` создается сквозной для кликов (`Qt.WA_TransparentForMouseEvents`) черный слой, регулирующий прозрачность от `0.0` (полная яркость) до `0.95` (ночной режим).
2. **Барьер для мыши (Mouse Trap / Sticky Edges):**
   Программное ограничение перехода курсора с 27" монитора на 7" экран при обычном движении мыши. Переход разрешается только при зажатой клавише `Alt` (при этом касания пальцем по 7" экрану работают всегда).
3. **Защита от отвала HDMI/USB (Hotplug Recovery):**
   Подписка на сигналы `QGuiApplication.screenAdded` / `screenRemoved`. Если экран мигнул или ПК вышел из сна, менеджер автоматически перехватывает улетевшие на основной монитор окна и возвращает их в сетку `720x600` второго экрана.
4. **Тач-жесты (Swipe Gestures):**
   * Свайп двумя пальцами сверху вниз — включить Dimmer (затемнить экран).
   * Свайп от левого края (от сайдбара вправо) — циклическое переключение между открытыми приложениями.

## 7. Стек библиотек и структура проекта

### 7.1. Зависимости (`requirements.txt`)
* `PySide6` — графический интерфейс, WebEngine, обработка Touch-событий.
* `pywin32` — управление окнами (`win32gui`, `win32con`, `win32api`, `win32process`).
* `psutil` — мониторинг запущенных процессов и связка `exe -> PID -> HWND`.
* `pycaw` — управление громкостью отдельных аудио-сессий Windows.

### 7.2. Файловая архитектура
```text
subscreen_wm/
├── main.py                  # Точка входа, DPI Awareness, запуск QApplication
├── config.json              # Координаты экрана, список отслеживаемых .exe, настройки яркости
├── requirements.txt         # Зависимости проекта
├── core/
│   ├── window_manager.py    # Поиск HWND, обрезка рамок, позиционирование (720x600)
│   ├── focus_guardian.py    # WS_EX_NOACTIVATE, возврат фокуса и курсора на 1-й экран
│   ├── mouse_barrier.py     # Блокировка случайного перехода курсора между экранами
│   └── aida_reader.py       # Чтение Shared Memory (mmap) из AIDA64
└── ui/
    ├── main_window.py       # Главное окно 800x600 (sidebar_frame + workspace_stackedW)
    ├── dimmer_overlay.py    # Прозрачный слой для регулировки яркости
    └── modules/
        ├── sensors_view.py  # Кастомные карточки датчиков (PySide6 QPainter / QProgressBar)
        └── youtube_view.py  # QWebEngineView с тач-оптимизацией и кастомным CSS
```

## 8. План реализации (Roadmap)

* **Этап 1 (MVP Core):** Создание базового окна `800x600` с сайдбаром на втором мониторе + реализация `WindowManager` (захват окна `happ`, удаление рамок, вписывание в `720x600`).
* **Этап 2 (Stealth Touch):** Внедрение `FocusGuardian` — тестирование флага `WS_EX_NOACTIVATE`, автовозврата фокуса и курсора мыши в полноэкранных играх на основном мониторе.
* **Этап 3 (Встроенные модули):** Подключение `QWebEngineView` для YouTube и написание парсера `AIDA64 Shared Memory` с отрисовкой виджетов телеметрии.
* **Этап 4 (Полировка):** Добавление программного диммера яркости, восстановления после сна (Hotplug Recovery) и микшера звука.
